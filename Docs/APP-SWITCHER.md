# 遥控器应用切换（0.4.13）

将按键动作设为 **Command + Tab 切换应用** 并保存。已有的相同映射自动使用新交互，不重写用户配置：

- 按一下并松开，打开 macOS 原生应用切换栏。
- 左右选择应用；上下也可选择。再按打开切换栏的键，选择下一项。
- **OK** 确认；**返回** 取消。不发送 Enter 到目标应用。
- 反向 ⌘⇧Tab 映射从反方向打开，再按该键继续反向选择。

只在切换栏打开时临时接管遥控器按键，关闭后恢复原有普通或鼠标键位。按其他普通按键会取消本次选择，不顺带执行其原动作；原语音键开始录音时先关闭切换栏。保存、切换型号、连招录入、锁屏、休眠、断连和退出也会清理。无操作 20 秒取消，键盘或鼠标操作会结束接管。不增加空闲轮询或常驻输入监听。

实现使用独立的 Quartz private event source，保持左 Command，确认时只释放自己的修饰键，取消时先发送 Escape。开始前拒绝已有修饰键按住的情况。所有遥控器键的原动作均确认被临时抑制之后才打开；关闭后的最后一个物理按键松开，再恢复 HID 映射。其他重映射工具修改了键位时取消，不强行抢回。

云端隔离测试覆盖按键配对、导航、确认/取消、超时、重复使用、权限失败、外部输入结束及映射数据往返；不向 CI 的 macOS 会话投递输入。云端测试不能代替真实遥控器与 macOS 切换栏验收。

0.4.13 修复了 0.4.12 偶发无法再次打开：投递到 HID event tap 的模拟 Command 会出现在 HID 状态表中，不能把该位当成实体键再次写入 Command-up。回归测试模拟这两张状态表同步变化，连续 50 轮确认、取消和外部输入结束，要求每轮都清掉本次模拟的 Command。
