# VoiceKey 点按录音测试版（0.4.11）

Google ATVV 1.0 遥控器语音键：**按一下开始，再按一下结束**。松手后继续使用遥控器麦克风收音，不需要按住遥控器或键盘。

## 使用

1. 打开 VoiceKey，允许麦克风和辅助功能；麦克风选择 **Chromecast Mic** 或系统默认，然后离开音频电平预览页。
2. VoiceKey 仍设置独立的长按快捷键，例如右 Command；点按键可以是 Fn，但不能与长按键复用同一修饰键。Remote Vibe 自动读取、保持和释放长按键，你不需要手按它。
3. Remote Vibe 顶部选择 **语音：VoiceKey** 和 **点按开关**，点击目标输入框。
4. 遥控器语音键按一下开始，说完再按一下结束，等待文字出现。

目前点按开关用于 Google ATVV 1.0（原语音键及映射为“遥控器麦克风”的普通键）。Google 旧协议可选“按住说话”；小米保留原有按住说话，不宣称支持点按保持。微信模式同样可由 Remote Vibe 保持和释放 Fn。

## 实现与边界

- 原语音键松开会停止物理按住流；Remote Vibe 随即请求宿主软件音频流，在同一个逻辑录音会话中继续收音，不提前松开 VoiceKey 的快捷键。
- 第二次语音键按下会关麦，等待尾段排空，再释放快捷键、停止虚拟音频并恢复默认输入。开麦、无音频或关麦确认失败、断连、休眠、用户会话失活和退出都会清理，迟到的开麦回复不能重新开始录音。
- 点按模式不沿用原按住模式的 55 秒上限；通过原有 4 秒保活保持遥控器软件音频流。非录音时不增加定时器或常开麦。
- 每次开始时只读 VoiceKey 的公开 settings.json 中的长按键和麦克风设置，不读取凭据、不写配置、不读取识别文本。识别与上屏由 VoiceKey 处理。
- VoiceKey 自身音频电平预览不由 Remote Vibe 关闭。

自动化使用假时钟、假遥控器消息和不投递的键盘事件，覆盖第一次松手后的软件续流、第二次停止、快速点击、迟到回复、失败与断连，以及原有按住模式回归。真实固件的通知顺序、续流间隙、实际上屏和松手后持续收音仍须用户实测，云端通过不等于实机通过。

这是 DD89527 fork 测试版，不是上游正式发布。适配格式基于 [VoiceKey v1.7.1 设置](https://github.com/J3n5en/voicekey/blob/v1.7.1/app/src-tauri/src/settings.rs)。
